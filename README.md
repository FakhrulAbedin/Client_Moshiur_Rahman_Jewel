# Sheikh Md. Moshiur Rahman Jewel — Executive Portfolio

Upload index.html, styles.css, script.js and the assets folder to your hosting document root. Open index.html to view locally. No build or dependency installation is required.

Design: charcoal #202b2b, warm ivory #faf9f5, bronze #886335, pale gold #d8bd8d. Responsive layout, mobile navigation, email/telephone/LinkedIn links and downloadable CV included.

Content is based on the supplied CV. Early-career entries are summarized without dates because the source contains overlapping dates and duplicated text. Metrics retain their employer context. Three supplied portraits are optimized as WebP. The original CV is included unchanged.

Typography: Inter in weights 400–800, inspired by the supplied Shohag Fardin Oron site. Loaded via Google Fonts with system sans-serif fallbacks.
